NetWarden 0.2 - сканер локальной сети и аудит безопасности для Windows

ЗАПУСК
 1. Распакуйте архив целиком.
 2. Дважды щёлкните BUILD_NetWarden.bat - через пару секунд появится NetWarden.exe и запустится сам.
    Ничего устанавливать не нужно: используется компилятор, уже встроенный в Windows 10/11.
 3. Дальше пользуйтесь NetWarden.exe - его можно копировать на другие компьютеры.

КАК ПОЛЬЗОВАТЬСЯ
 Поле "Цели" заполняется автоматически вашей локальной сетью (кнопка "Моя сеть" вернёт её).
 Формат целей: 192.168.1.0/24, 10.0.0.1-50, 10.0.0.1-10.0.0.99, server.local, @list.txt
 Нажмите "Старт" и подтвердите, что у вас есть право сканировать эту сеть.

ВКЛАДКИ
 Результаты      - дерево: хост -> порты -> уязвимости, справа подробности
 Устройства      - таблица: IP, имя, MAC, производитель, ОС, тип, службы, число находок
 Карта сети      - схема сети (подсети, шлюз, хосты); цвет рамки = самая серьёзная находка; можно сохранить в PNG
 Уязвимости      - все находки с описанием и пошаговой рекомендацией "КАК ИСПРАВИТЬ"
 Порты и службы  - все открытые порты TCP/UDP с продуктом, версией и баннером
 (вкладки "Журнал" и "История" убраны из интерфейса по просьбе пользователей; результат виден сразу по ходу сканирования)

КНОПКА «ИСПРАВИТЬ»
 Под описанием находки (вкладки «Результаты» и «Уязвимости») есть кнопка.
 - Если находка относится к ЭТОМУ компьютеру и для неё есть автоисправление (SMB, RDP, Telnet, SNMP, UPnP,
   открытые порты служб, TLS 1.0/1.1), программа покажет, что именно изменится, и после вашего подтверждения
   выполнит изменения через PowerShell. Windows запросит права администратора (UAC).
   Результат и команда отката выводятся на экран и сохраняются в %APPDATA%\NetWarden\fixes.log
 - Для остальных находок и для других компьютеров кнопка открывает подробную пошаговую инструкцию
   (Windows / Linux / роутеры) и готовый скрипт, который можно скопировать или сохранить в .ps1.
 NetWarden не выполняет команды на удалённых компьютерах - только на том, где запущен.

ЧТО ОПРЕДЕЛЯЕТСЯ
 Активные устройства: ARP (в своей подсети, надёжно), ping, TCP-проверки
 Имена: DNS, NetBIOS;  MAC и производитель (встроенная неполная база; можно дополнить файлом
 %APPDATA%\NetWarden\oui.txt со строками вида "AABBCC Название производителя")
 Открытые порты TCP + службы и версии (SSH, HTTP/HTTPS, FTP, SMTP, SMB, RDP, БД и др.), TLS
 UDP-службы: DNS, NTP, SNMP, SSDP/UPnP, NetBIOS
 Операционная система: по баннерам служб и SNMP/UPnP, по набору портов, по TTL, по MAC (оценка, не гарантия)
 Уязвимости: правила с CVE/CVSS (метки "подтверждено" / "вероятно"), TLS, веб, анонимный FTP, SNMP public

НОВОЕ В 0.1
 - На карте сети устройства теперь рисуются настоящими иконками по типу: маршрутизатор/шлюз, компьютер,
   сервер базы данных, веб-сервер, сетевое оборудование - вместо текстовых подписей WIN/NIX/DB и т.п.
 - Обновление баз CVE (NVD) стало устойчивее к сбоям и при ошибке показывает её причину (HTTP-код сервера,
   фрагмент ответа или текст исключения) вместо простого счётчика "ошибок: N" без деталей.


 - Свой диапазон портов: в списке профилей выберите "Свой диапазон" и впишите, например, 1-6000 или 22,80,443,8000-8100.
 - Галочка "Без обнаружения" (режим -Pn): объяснение см. в подсказке при наведении на неё в программе, и ниже в этом файле.
 - Галочка "Слабые пароли": проверка FTP и веб-форм HTTP Basic Auth по короткому встроенному словарю типовых пар
   логин/пароль (admin/admin и т.п.). ВАЖНО: SSH, RDP и большинство СУБД (MySQL, MSSQL, PostgreSQL, MongoDB...) этой
   проверкой НЕ охвачены - для них нужна полная реализация сетевого протокола с рукопожатием/шифрованием, а в этой
   однофайловой сборке на встроенном компиляторе Windows нет доступа к сторонним библиотекам (например, SSH.NET),
   которые это умеют. Для полноценного перебора паролей по этим протоколам используйте специализированные инструменты
   (Hydra, Medusa, NetExec) на выделенном для тестов компьютере.
 - Эвристические веб-проверки: метод HTTP TRACE, пассивные признаки SQL-инъекции и отражённого XSS (по безопасному
   нейтральному маркеру, без реальной атаки), раскрытие путей/трассировки стека через страницы ошибок.
 - Кнопка "Обновить базы CVE": опрашивает публичную базу NVD (nvd.nist.gov) по продуктам и версиям, найденным при
   сканировании, и добавляет совпавшие CVE как находки. Для российской базы БДУ ФСТЭК стабильного публичного API нет,
   поэтому вместо автоматической сверки к каждой находке добавлена прямая ссылка для проверки на bdu.fstec.ru.
 - У каждой находки теперь два отдельных раздела: "Как может воспользоваться злоумышленник" (сценарий атаки) и
   "Как исправить" (пошаговая инструкция), плюс ссылки на NVD/БДУ ФСТЭК.
 - Инструкция по SMB переписана: явно объяснено, почему порт 445 может снова появиться в находках после "исправления",
   если в сети нужен общий доступ к файлам - это ожидаемое поведение Windows, а не сбой программы.

О КНОПКЕ "БЕЗ ОБНАРУЖЕНИЯ" (-Pn)
 По умолчанию NetWarden сначала проверяет, "жив" ли хост (ARP в своей подсети, ping, пробные TCP-подключения), и
 сканирует порты только у тех адресов, которые ответили. Это быстрее, но если хост блокирует ping и не отвечает на
 пробные подключения (строгий файрвол, фильтрация ICMP), он ошибочно считается выключенным и пропускается - хотя
 порты на нём на самом деле открыты. Галочка "Без обнаружения" отключает эту проверку: сканируются порты у ВСЕХ
 адресов диапазона без исключения. Минус - сканирование идёт намного дольше, особенно на больших диапазонах
 (например, /16 или "Полный" профиль портов). Включайте её, если подозреваете, что хосты пропускаются незаслуженно.

ВАЖНО
 Сканируйте только свои системы или те, на которые есть письменное разрешение.
 Определение ОС без привилегированных сокетов - эвристика; точность ниже, чем у nmap.
 Антивирус может отреагировать на сканер портов и подбор паролей - это нормально для такого класса программ.
 Обновление баз CVE требует интернет-соединения и может занимать до пары минут из-за ограничений NVD API без ключа.

НОВОЕ В 0.1 (визуальный редизайн)
 - Интерфейс переработан в тёмной "военно-футуристичной" стилистике: глубокий тёмно-синий/графитовый фон,
   полупрозрачные панели с градиентом, тонкая голубая окантовка, бирюзовый акцент на основных действиях,
   мягкое свечение у активных элементов. Без жёлтого цвета где-либо (запрошено отдельно).
 - Главный фокус экрана - верхняя "героическая" панель статуса: крупная кнопка "Начать сканирование" /
   "Стоп", статус (готов / сканирование / завершено), цель, число найденных хостов и время сканирования.
 - Списки устройств, портов и уязвимостей перерисованы в тёмной теме с цветной полосой серьёзности слева
   и бирюзовым выделением выбранной строки. Вкладки оформлены как панель с подсветкой активной вкладки.
 - Карта сети: линии связей и подложки подсетей перекрашены под новую палитру.
 - Вся логика сканирования, проверок и исправления уязвимостей не менялась - переработан только внешний вид.

ПОРТАТИВНЫЙ РЕЖИМ (НОВОЕ В 0.2)
 Если рядом с NetWarden.exe лежит файл portable.txt (пустой, достаточно самого факта его наличия),
 программа работает в портативном режиме: журнал исправлений, пользовательская база MAC-адресов
 (oui.txt) и временные скрипты PowerShell хранятся в подпапке Data рядом с .exe, а не в
 %APPDATA%\NetWarden. Это значит:
   - программу можно носить на флешке и запускать на разных компьютерах без следов в системе;
   - чтобы "сбросить" данные - просто удалите подпапку Data;
   - чтобы вернуться к обычному режиму (хранение в профиле пользователя) - удалите portable.txt.
 В шапке программы при включённом портативном режиме появляется пометка "ПОРТАТИВНЫЙ РЕЖИМ".
 В архиве NetWarden-0.1-Portable.zip файл portable.txt уже создан заранее - после сборки
 (BUILD_NetWarden.bat) программа сразу запустится в портативном режиме.
