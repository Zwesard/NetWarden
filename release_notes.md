## NetWarden 0.3

Исправление ошибки компиляции в отрисовке карты сети (CS0103) и добавление автоматической
сборки/публикации релизов через GitHub Actions — теперь `NetWarden.exe` в этом релизе собран
и проверен на настоящей Windows, а не только текстовым разбором исходников.

### Начиная с 0.1-0.2 (включено в эту сборку)
- Военно-футуристический тёмный интерфейс: глубокий тёмно-синий/графитовый фон, полупрозрачные
  панели, тонкая голубая окантовка, бирюзовый акцент, без жёлтого цвета.
- Портативный режим: файл `portable.txt` рядом с exe — все данные хранятся в папке `Data` рядом
  с программой, а не в `%APPDATA%`. Можно носить на флешке.

### Как запустить
Скачайте **NetWarden.exe** из этого релиза (или архив ниже) и запустите — ничего устанавливать
не нужно. Portable-версия хранит данные рядом с собой.

> Сканируйте только свои системы или системы, на сканирование которых у вас есть разрешение.
