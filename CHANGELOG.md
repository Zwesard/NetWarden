# Changelog

## 0.3
- Исправлена ошибка компиляции CS0103 в отрисовке карты сети: `GraphicsPath` подложки подсети
  выходил из области видимости из-за отсутствующих фигурных скобок в цепочке `using`.
- Добавлен workflow GitHub Actions: сборка и публикация релиза на настоящей Windows при создании тега.

## 0.2
- Портативный режим: файл `portable.txt` рядом с `NetWarden.exe` переключает хранение всех данных
  (журнал исправлений, база MAC-адресов, временные PowerShell-скрипты) в папку `Data` рядом с exe
  вместо `%APPDATA%\NetWarden`.
- В шапке программы отображается пометка "ПОРТАТИВНЫЙ РЕЖИМ", когда он включён.

## 0.1
- Визуальный редизайн интерфейса: тёмная военно-футуристичная тема (глубокий тёмно-синий/графитовый
  фон, полупрозрачные панели с градиентом, тонкая голубая окантовка, бирюзовый акцент, мягкое
  свечение активных элементов), без жёлтого цвета в палитре.
- Центральная "героическая" панель статуса сканирования: статус, цель, число найденных хостов,
  время сканирования, крупная кнопка "Начать сканирование" / "Стоп".
- Списки устройств/портов/уязвимостей, дерево результатов и карта сети перерисованы в новой теме.
- Логика сканирования, проверок и автоисправления не менялась.

## 0.8 и ранее
- Сканирование локальной сети (ARP/ping/TCP), определение ОС, MAC-адресов и производителей,
  TCP/UDP-порты и службы, проверки уязвимостей (встроенная база + обновление из NVD), проверки
  TLS/веб/FTP/SMB/слабых паролей, карта сети, автоисправление части находок, ручной диапазон портов.
