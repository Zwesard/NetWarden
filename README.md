# NetWarden

Сканер локальной сети и аудит безопасности для Windows, вдохновлённый XSpider.

Один файл на C# (`NetWarden.cs`), собирается встроенным в Windows компилятором `csc.exe` —
ничего дополнительно устанавливать не нужно.

## Установка и запуск

1. Скачайте архив из раздела [Releases](../../releases) (обычный или **Portable**) и распакуйте.
2. Если в архиве уже есть `NetWarden.exe` — просто запустите его.
   Если нет (собираете из исходников) — запустите `BUILD_NetWarden.bat`: он соберёт
   `NetWarden.exe` и сразу откроет программу.

**Portable**-версия хранит все свои данные (журнал исправлений, базу MAC-адресов, скрипты)
в папке `Data` рядом с `.exe`, а не в `%APPDATA%` — её можно носить на флешке.

## Возможности

- Обнаружение активных устройств в сети (ARP, ping, TCP) с определением ОС, MAC и производителя.
- Сканирование TCP/UDP-портов, определение служб и версий.
- Проверка уязвимостей: встроенная база CVE + обновление из NVD, проверки TLS, веб-сервера,
  анонимного FTP, SMB (отдельная проверка именно SMBv1, а не просто "порт открыт"), слабых паролей.
- Карта сети, список устройств, список портов и служб, список находок с рекомендациями
  "как исправить" и описанием, как уязвимость может быть использована злоумышленником.
- Кнопка "Исправить": для части находок — автоматическое исправление на этом компьютере
  (через PowerShell с запросом прав администратора), для остальных — подробная инструкция.

Подробности и известные ограничения — в `README.txt` внутри каждого архива.

## Сборка и релизы

Workflow `.github/workflows/release.yml` при создании тега `v*` сам собирает `NetWarden.exe`
на настоящей Windows (`windows-latest`) тем же компилятором, что и `BUILD_NetWarden.bat`,
и публикует релиз с обычным и Portable-архивом. Можно запустить и вручную: вкладка
**Actions → Build & Release → Run workflow**.
